# Simple Interest Calculator

A simple Bash script that calculates simple interest based on the principal amount, annual rate of interest, and time period.

## Description

This project is created as part of the Introduction to Git and GitHub final project.

The calculator uses the following formula:

Simple Interest = (Principal × Rate × Time) / 100

## Usage

Run the script using:

bash simple-interest.sh

Enter the principal amount, rate of interest, and time period when prompted.
